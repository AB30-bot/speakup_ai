02

Architecture

Feature-folder structure — the React equivalent of the clean-architecture separation from the original spec, scaled to app size.

src/
  app/            routing, providers, top-level layout
  features/
    auth/         sign-in, session state
    scenarios/    curated personas + AI-generated scenario logic
    conversation/ live voice session UI + Gemini chat + speech I/O
    evaluation/   scoring engine, session report
    gamification/ XP / levels / coins / streaks / achievements
    career/       career mode ladder, infinite level generation
    dashboard/    stats, charts, progress
  lib/
    firebase.ts   Firebase init
    gemini.ts     Gemini client (calls the Netlify function only)
    speech.ts     Web Speech API wrappers
  types/          shared TS types (Scenario, SessionReport, UserProfile...)
netlify/functions/
    gemini-proxy.ts   holds GEMINI_API_KEY server-side

State: React Context + hooks for auth/session state — no heavier state library needed at this scope.

03

Data Model (Firestore)

  • users/{uid} — profile, level, xp, coins, streakCount, lastSessionAt, careerLevel, unlockedAchievements[], weakSkills[]
  • users/{uid}/sessions/{sessionId} — scenario used, transcript, per-category scores, overall score, XP/coins earned, timestamp
  • scenarios — the ~8 fixed curated personas, seeded once

AI-generated scenarios (Career Mode level 11+, or "Generate New Scenario") are not persisted as a shared library — they're generated per-request and stored only inside that user's session record, since they're one-off by design.

04

Core Features

Auth

Google sign-in via Firebase Auth. First login creates users/{uid} with defaults (level 1, 0 XP, careerLevel 1).

Scenario selection

Grid of curated personas plus a "Generate New Scenario" action — Gemini invents a fresh persona/mood/objective/twist as structured JSON.

Live conversation

Web Speech API captures mic input → transcribed text sent to Gemini with persona system-prompt + history → reply spoken back via speechSynthesis. If the browser lacks SpeechRecognition (e.g. Firefox), falls back to text-input chat rather than blocking the feature.

AI evaluation

At session end, the transcript is scored via structured output: confidence, fluency, clarity, grammar, vocabulary, persuasiveness, pace, filler words, professionalism, structure, emotional impact, naturalness — each 0–100 with a one-line "why." Overall = weighted average.

Session report

Overall score, XP/coins earned, strengths/weaknesses, best sentence, transcript, comparison to the user's rolling average.

Gamification

XP scaled by score + difficulty, levels from an XP curve, coins as a secondary currency (cosmetic-only, no shop in v1), streak from lastSessionAt date diff, achievements from simple rule checks.

Career Mode — infinite

careerLevel never caps. Levels 1–10 use the fixed themed progression (stranger → job interview → investor pitch → TED talk...). Level 11+: Gemini generates the next level using the level number + the user's weakSkills to scale difficulty — genuinely endless, no hand-authored content required.

Dashboard

Level/XP/streak/session-count stat cards, score-over-time line chart, achievement badges row.

AI Coach

Lightweight in v1: one Gemini-generated paragraph after each session highlighting the top recurring weakness + one suggested next scenario. Full long-term training plans are future work.

05

Gemini Integration

All calls route through one Netlify function (gemini-proxy) holding GEMINI_API_KEY server-side. Three request modes: chat (persona conversation turn), evaluate (structured scoring), generateScenario (structured scenario). Structured modes use Gemini's JSON-schema-constrained output, so the frontend never parses free text.

06

Error Handling

  • Mic permission denied → inline prompt to re-enable, offer text-input fallback
  • Gemini call fails mid-conversation → retry once, then show a reconnect state without losing the transcript so far
  • Firestore write fails on session save → keep the report visible client-side, retry in background, warn if it ultimately fails

08

Testing

Unit tests (Vitest) for the pure-logic pieces — XP/level curve, streak calculation, scoring aggregation. Manual QA for the conversation flow and speech I/O, which are hard to meaningfully unit test. No E2E suite in v1 — future work.

09

Deployment

  • speakup_ai becomes its own git repo, pushed to GitHub via the github-publish skill (already authenticated)
  • Netlify site connected to that repo via their dashboard (not CLI) — auto-deploys on push to main
  • GEMINI_API_KEY and Firebase config set as Netlify environment variables, never committed
